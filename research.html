Infeence for Identified Sets via Classification-Based Metropolis-Hastings
In many econometric applications the identified set is defined by a criterion built from restricted features of the data distribution (moment conditions), a choice often adopted because of the intractability of the likelihood in complex models. Such criteria do not exploit all the information in the data, yielding outer identified sets rather than sharp ones. In this paper I exploit the fact that the likelihood ratio can be recovered from the solution to a classification problem, which restores tractability. I can then construct confidence sets for the identified set in structural models using the sample counterpart of this classification-based likelihood. This requires only that the model can be simulated, not that its likelihood is tractable. The substitution yields a quasi-likelihood ratio statistic and allows me to sample from the quasi-posterior using the classification-based Metropolis–Hastings algorithm. I show that if the estimated classifier converges to the oracle, the resulting confidence sets attain asymptotically valid frequentist coverage.
